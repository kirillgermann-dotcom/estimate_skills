## Оценка трудозатрат 1С

При запросе трудооценки задачи для 1С:ERP используй
skills/estimate-task/SKILL.md.

Общую оценку составляй из применимых ролевых работ:
- разработчик: skills/estimate-developer/SKILL.md;
- аналитик: skills/estimate-analyst/SKILL.md;
- консультант ERP: skills/estimate-consultant/SKILL.md.

Не добавляй ролевые часы автоматически. Для каждой работы указывай
основание, результат и исполнителя. Если данных недостаточно,
показывай допущения и отдельно оценивай этап уточнения.
Не меняй нормативы ролевых скиллов без явного основания.
