## Оценка трудозатрат 1С

При запросе трудооценки задачи для 1С:ERP используй
.agents/skills/estimate-task/SKILL.md.

Общую оценку составляй из применимых ролевых работ:
- разработчик: .agents/skills/estimate-developer/SKILL.md;
- аналитик: .agents/skills/estimate-analyst/SKILL.md;
- консультант ERP: .agents/skills/estimate-consultant/SKILL.md.

Не добавляй ролевые часы автоматически. Для каждой работы указывай
основание, результат и исполнителя. Если данных недостаточно,
показывай допущения и отдельно оценивай этап уточнения.
Не меняй нормативы ролевых скиллов без явного основания.

В таблицах декомпозиции и итогов всегда сохраняй столбец «Размер»,
в том числе в сокращённой оценке. Используй шкалу XS/S/M/L/XL/Epic
из .agents/skills/estimate-developer/SKILL.md. Размер строки определяй
по её часам, размер всей задачи — по сумме часов всех участвующих ролей.
При диапазоне часов показывай диапазон размеров, если категории различаются;
при отсутствии численной оценки указывай «На уточнении».
